# A simple recipe website

This is a simple recipe website built using Django, PostgreSQL, and Angular.

# Setup

This project's Python dependencies are managed by [`uv`](https://github.com/astral-sh/uv); installation instructions [are here](https://github.com/astral-sh/uv) if you don't already have it installed.

Clone the repository:

```
git clone https://github.com/shanepelletier/simple-recipe-website
```

Then `cd` into the cloned repository and install the required dependencies:

```
cd simple-recipe-website; uv sync
```
